# SQLite + Python in VS Code Course Plan

## Goal

Create a stepped beginner course that helps students learn how to:

- use SQLite as a simple local database
- connect to SQLite from Python
- create tables
- add, query, update, and delete data
- build a small end-to-end project in VS Code

## Target learner

- total beginners
- high school or early college students
- learners with little or no database experience
- learners who may also be new to Python files, terminals, and VS Code

## Total time

**About 7 hours total**, with flexibility to shorten or extend activities.

| Lesson | Focus | Estimated Time |
| --- | --- | --- |
| Lesson 1 | Setup and first connection | 60 minutes |
| Lesson 2 | Create tables and add data | 75 minutes |
| Lesson 3 | Query data with SELECT | 75 minutes |
| Lesson 4 | Filter, sort, and summarize | 75 minutes |
| Lesson 5 | Multiple tables and joins | 75 minutes |
| Lesson 6 | Mini project in Python | 60 minutes |
| **Total** |  | **420 minutes / 7 hours** |

## Required teaching pattern for each lesson

Each lesson should include:

1. **Learning goals**
2. **Why this matters**
3. **Key theory**
4. **Glossary**
5. **Step-by-step code**
6. **Student activity**
7. **Stretch challenge**
8. **Exit check / reflection**

## Core tools

- **VS Code**
- **Python 3**
- Python `sqlite3` module
- SQLite database file such as `school.db` or `library.db`
- VS Code terminal

## Suggested instructional approach

- Start every lesson with a quick demonstration.
- Keep examples small and visible.
- Introduce one new SQL idea at a time.
- Pair every SQL command with a Python example.
- Use real beginner-friendly contexts such as books, students, or games.
- End each lesson with a short activity students can complete independently.
