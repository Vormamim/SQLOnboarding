# SQLOnboarding: SQLite Beginner Course Plan

Beginner-friendly course planning materials for learning SQLite with Python in VS Code.

## Course overview

This repository contains a stepped tutorial plan for total beginners. The full sequence is designed for **6–8 hours** and detailed in [course-plan.md](course-plan.md). The course is organized as a series of Markdown lessons with:

- key theory
- beginner glossary terms
- explicit code examples
- guided student activities

## Suggested lesson sequence

1. [Lesson 1 - Setup and First Database Connection](lessons/lesson-01-setup-and-first-connection.md)
2. [Lesson 2 - Create Tables and Add Data](lessons/lesson-02-create-tables-and-add-data.md)
3. [Lesson 3 - Query Data with SELECT](lessons/lesson-03-query-data-with-select.md)
4. [Lesson 4 - Filter, Sort, and Summarize](lessons/lesson-04-filter-sort-summarize.md)
5. [Lesson 5 - Work with Multiple Tables](lessons/lesson-05-multiple-tables-and-joins.md)
6. [Lesson 6 - Build a Mini Project in Python](lessons/lesson-06-mini-project.md)
